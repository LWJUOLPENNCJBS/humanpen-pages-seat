AskYourPDF vs HumanPen Start Project: A Per-Document Ceiling vs a Per-Project Ceiling

AskYourPDF is the better choice when the obstacle is one large document. You have a PDF, a slide deck or a scanned report and you need to interrogate it, summarise it, or move its contents into a form, and the plan you are on sets how big that document can be: the free tier allows up to 100 pages per document and 15MB max upload, $11.99/month allows up to 2,500 pages per document and 31MB, and $14.99/month allows up to 6,000 pages per document and 877MB. It also carries 40+ free AI tools alongside the document work.

HumanPen Start Project is the better choice when the obstacle is the analysis. The document is one input among several, the question is empirical, and the thing you owe someone at the end is a report with tables, figures and code. It plans first, starts when you confirm, runs Python or R in an isolated sandbox, and delivers a .docx report, 300 dpi figures, three-line tables, slides with speaker notes and the code.

AskYourPDF raises the ceiling on a document. HumanPen removes the per-document question by making the unit a project.

How the workflows differ

1. One document at a time vs one project at a time

AskYourPDF's design assumption is a document. The plan table is a grid of pages and megabytes per file, which tells you what the product is optimising for: getting a large, awkward file into a state where you can ask it things. That is a real problem — a long evaluation report with the answer buried in an annex, a form that has to be filled from another form, a scanned appendix nobody has opened in years.

HumanPen Start Project assumes a bundle. A project can hold spreadsheets, documents, PDFs and a zip, up to 5 GB total, and the question is stated in a sentence rather than implied by a file. The difference shows up when the answer is not in any of the files. If the question is "what does this report say about attrition", the document tool wins outright. If the question is "does attrition differ by arm once you adjust for baseline", no document contains that sentence yet; it has to be computed.

2. A ceiling that moves vs a ceiling that does not

This is the sharpest structural difference between the two products, and it is worth stating plainly rather than as a table row.

AskYourPDF lets you buy a bigger document. Free is 100 pages and 15MB; $11.99/month takes you to 2,500 pages and 31MB; $14.99/month takes you to 6,000 pages and 877MB. The upgrade path is legible, and if your recurring problem is one enormous PDF, that is the right thing to sell you.

HumanPen Start Project does not have that ladder. The intake is 5 GB total per project at every scope, and what changes between projects is the deliverable and the work in the plan, not the ceiling. Sixty scattered PDFs of two megabytes each are not a problem for a project intake in the way they are for a per-document limit, because the limit is not applied per file. Conversely, one single file approaching 5 GB would strain the intake, which is the honest trade: the ceiling is generous in aggregate and indifferent to how you divide it.

3. An answer vs a delivery

AskYourPDF's output is an answer or a filled form. You read it, you copy it, and the writing is still yours to do. That is a complete workflow for a support question, a contract clause, a form field.

HumanPen's output is a package, and the sequence before it matters as much as the package. Five stages — Describe, Plan, In progress, In review, Delivered — with work starting only after you confirm the plan. The public example shows what that confirmation looks like in practice: a secondary analysis of the International Stroke Trial, full analysis set 19,435 patients, primary endpoint death or dependency at 6 months, about 150 missing outcomes given a sensitivity analysis — restated back to the user before anything runs. Before delivery a second AI reviews the result; the page shows "Review passed (round 1)", with the endpoint matching, the populations adding up, a clean rerun reproducing the numbers and all 11 references found one by one.

A chat answer and a reviewed delivery are different artefacts with different failure modes. The first fails by being vague; the second fails by being wrong in a way a reviewer will find. Only one of those failure modes is worth building a checkpoint for.

Uploading files and what comes back

AskYourPDF takes a document and gives you conversation, summaries and form filling over it, with the per-document page and size ceiling set by your plan. Its free tier is genuinely usable for a single paper: 100 pages covers most journal articles, and 15MB covers most of them as files.

The moment the unit of work stops being "a document" and becomes "a study", the shape of the intake becomes the constraint. A study bundle is a survey export, a codebook, a set of reference PDFs, a journal template and a folder of figures — mixed formats, no natural page count, no single file to point at. HumanPen Start Project handles that as one intake: Excel, CSV, Word, PDF and zip, up to 5 GB total, and one plan covering the whole thing.

What comes back is specified: a .docx report, charts at 300 dpi to journal standards, three-line tables and captions, a .pptx with speaker notes, and the code. If the project is a re-analysis, the numbers in the report are the ones the code produces, which is why the rerun check ("a clean rerun reproduces the results exactly") appears in the review list rather than in the marketing copy.

Price shape and governance

AskYourPDF prices a document budget. Free covers 100 pages per document and 15MB; $11.99/month covers 2,500 pages and 31MB; $14.99/month covers 6,000 pages and 877MB. It is a clear ladder, and it is priced against the thing that costs the vendor money: ingested pages, one document at a time.

HumanPen Start Project is priced against a project rather than a page count, and there is no per-page charge to overrun. The published constraint is 5 GB total per project plus the scope in the plan you approve. We do not quote a price here, because the pages we read do not publish a price list for this work.

Governance splits along the same line. AskYourPDF's pages point to its own security and compliance terms; we did not audit the processing agreement, so treat that as a pointer rather than an assessment. HumanPen's page is more specific about mechanics: transport encryption, an isolated sandbox per project, no sharing across users, no use for training, deletion at any time, and retention for 6 months after the last activity with a reminder 3 days before expiry.

For a researcher, the practical question is usually not "is this compliant" in the abstract but "can I answer my ethics committee in one paragraph". The retention and isolation statements are the ones that paragraph needs; the compliance certificate is the one a procurement team needs. Different readers, different lines.

When to choose which

Choose AskYourPDF if the job is a document: you have one big file, the answer is inside it, and you want to ask, summarise and extract without reading it page by page. The free tier's 100 pages and 15MB is a fair test, and the $11.99 and $14.99 tiers exist for the files that outgrow it.

Choose HumanPen Start Project if the job is a result: the data needs to be analysed, the tables need building, the figures need to be journal-grade, and the code needs to exist so the numbers can be defended.

Use both if the document is evidence rather than the subject. Read the report in AskYourPDF to find what it claims and where; then take the dataset and the claim into HumanPen Start Project, confirm a plan, and produce the analysis that tests it. This is the normal shape of a replication or a secondary analysis: one tool tells you what the paper says, the other tells you whether it holds.

The mismatch to avoid is buying capacity for the wrong bottleneck — paying for a 6,000-page document allowance when the real constraint is that nobody has run the model yet, or commissioning an analysis of a report whose numbers you have not yet located.

FAQ

Is AskYourPDF free? Yes. The free tier allows up to 100 pages per document and 15MB max upload. Paid tiers raise the per-document ceiling: $11.99/month for up to 2,500 pages and 31MB, $14.99/month for up to 6,000 pages and 877MB.

What is the maximum file size on AskYourPDF? It depends on the plan: 15MB on the free tier, 31MB at $11.99/month, and 877MB at $14.99/month, each paired with a per-document page limit of 100, 2,500 and 6,000 respectively.

Can AskYourPDF analyse my dataset? The public pages we examined describe document conversation, summarising and form filling. They do not describe a statistical execution environment, a Python or R runtime, or a code deliverable. Analysing a dataset is a different job from interrogating a document about it.

Is there a page limit on HumanPen Start Project? No per-page limit is stated. The intake is Excel, CSV, Word, PDF and zip up to 5 GB total per project, the plan is confirmed before work starts, and delivery includes the report, figures, tables, slides and code.
