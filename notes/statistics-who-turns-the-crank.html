Who turns the crank on statistics? HumanPen and five statistical tools compared

A statistical result can appear in three ways. Someone clicks through a menu until a table shows up. Someone writes commands, runs them, keeps the syntax. Or someone describes the analysis and an agent writes and runs the code.

All three produce a number. They differ in what is left behind when the analyst walks away, and that difference is the whole argument here. Menus are fastest for exploration and teaching. Syntax is the strongest record for a single analyst. An agent is the only one of the three that can hand you the document and the audit at the same time.

What each public page actually describes

IBM SPSS Statistics: the menu as an institution

SPSS is the reference point for a certain kind of social science and clinical workflow, and its commercial shape reflects that: a Base subscription Starting at $99.00 USD Per Authorized User, add-on modules Starting at $79.00 USD Per Authorized User each, a free trial, and campus-wide licences with student licences at special academic pricing.

The workflow it describes is you, in the application, working through data prep, analysis and predictive modelling. That design has a virtue beyond convenience: because the interface constrains what you can ask for, two people trained on the same menus will run the same procedure, and a methods section saying "independent-samples t-test in SPSS" is a complete recipe for a reader who owns the software.

Its limit is the same thing. The menu is the method, and the method is not in the output. If someone without a licence needs to re-run the analysis, or to know which options were ticked, the output file is a photograph rather than a recipe.

Stata: documentation as the product

Stata's page argues reproducibility rather than ease: accurate, reproducible results, automated reporting with exports to Word, Excel, PDF and HTML, and backward compatibility — modern Stata understanding code written decades earlier.

Then there is the number that matters for anyone learning it: 19,000 pages of documentation detailing each feature, including formulas and fully worked examples. With free webinars, NetCourses and thousands of free community additions, the centre of gravity is the written record — a strong position for a chapter that has to be defended method by method.

What it asks of you is effort. The documentation is the product, and reading it is the work — fine if the analysis is yours and you will defend every choice, expensive if the analysis is a means to a report that is due.

JASP: the interface, deliberately minimal

JASP describes itself in one sentence that reads like a design brief: a free cross-platform program with a state-of-the-art graphical user interface, built so that "statistical practitioners reach maximally informative conclusions with a minimum of fuss". Free, cross-platform and GUI-first removes two usual barriers — licence budget and operating system — and the "minimum of fuss" framing tells you the intended user wants the analysis, not the programming. The page does not describe a code export.

jamovi: reproducibility inside one file

jamovi is free and open source, desktop always free, Cloud Guest free with no install and no credit card, and it is powered by R. The claim worth quoting is the one about the file: data, analyses and results save into a single file, which the page presents as the basis of reproducibility.

That is a clever piece of design, because it puts the audit trail in the artefact rather than beside it: hand someone the file and they have the data and the settings in one object. What it does not do, on the page's own description, is produce the manuscript.

RStudio: the script as the unit of work

RStudio's page describes the premier free, open-source development environment for R — Open Source Edition free under AGPL v3 — with RStudio Desktop Pro at $1204.00 per year for a commercial licence and priority support, and Posit AI available at $20 per month with a free trial.

This is the model in which the crank is turned by a person writing code, and the record is the script: the table, the figure and the sensitivity analysis are all functions of it. It also means the quality of the audit is the quality of the person's habits — a script under version control is a strong record, a session run in the console is not.

Where the audit trail actually lives

Line the five up and the difference is archival rather than statistical. In SPSS the trail is the output plus the memory of whoever ticked the boxes; in Stata and RStudio it is the syntax and the data; in jamovi it is the project file; in JASP it is the analysis as configured in the interface. Each suffices for the person who did the work and for a colleague with the same software. The failure case — a co-author or a new student who needs the same numbers without the software, six months later — is what pushes groups toward scripts, and toward services that deliver the code with the output.

How HumanPen runs this step

HumanPen does not put an interface in front of you. You describe the analysis and attach the files — Excel, CSV, Word, PDF or zip, up to 5 GB total — and the system returns a plan. Nothing runs until you confirm it; then the work happens in Python or R in an isolated sandbox, and a second AI reviews before delivery.

Three details matter for the statistics. First, the engine is Python or R, and analyses originally done in SPSS or Stata are redone in Python or R. That is a deliberate trade: you lose the familiar dialog boxes and gain an analysis anyone with a free interpreter can re-run.

Second, the review is numerical rather than rhetorical. The page's four checks include the primary endpoint matching (62.2% vs 63.5%, P = 0.072 in the published example), every analysis population adding up, and a clean rerun reproducing the results exactly. The fourth is bibliographic — all 11 references found, one by one.

Third, the awkward parts of a real dataset are handled explicitly. In the same public example, a secondary analysis of the International Stroke Trial with 19,435 patients in the full analysis set, roughly 150 missing outcomes are handled in a sensitivity analysis rather than dropped silently. That is the kind of decision a menu cannot make for you and a script makes only if someone thought of it.

What you get back is the report, figures at 300 dpi, three-line tables, a .pptx with speaker notes and the code. What you do not get is a slider: a revision means stating the new scope, confirming it, and receiving a new version while the old one is kept.

Decision rules

Click, if the analysis is the point. Teaching a methods class, checking a distribution before committing to a test, running a familiar procedure on a new sample — SPSS, JASP and jamovi are built for this, and the free options remove the budget argument entirely.

Script, if the analysis is yours to defend. A thesis chapter, a methods appendix, a re-analysis you expect to be challenged on. Stata's 19,000 pages and RStudio's script-and-project model both assume you want to own the reasoning, and they reward the effort with a record that holds up.

Commission, if the statistics are a step toward a document. A report, a submission, a set of results you have to reproduce with notes on where they differ. The plan fixes the analysis set before the numbers exist, the clean rerun is part of the review rather than an afterthought, and the code arrives with the prose so the next person can check rather than trust.

The mistake to avoid: buying a licence when you needed a document, or commissioning one when you wanted to understand the data yourself.

FAQ

Is IBM SPSS Statistics free for students? Not on the page we read. It offers a free trial and states that academic institutions have campus-wide licences and student licences at special academic pricing, so a free seat usually comes through your institution rather than the vendor's list price.

How much does Stata cost? We do not quote it. The home page we captured shows cart entries — a Stata/MP4 annual licence and a Stata/BE network maintenance term — but those are cart and maintenance items rather than product pricing, so we do not treat them as one.

Can JASP or jamovi produce a Word report and journal figures? Their pages describe the analysis and, for jamovi, a single reproducible project file. They do not describe a .docx report, 300 dpi figures or a slide deck, so we make no claim either way.

Why would HumanPen redo an SPSS analysis in Python or R? So the result can be re-run without the licence. The page states that analyses originally done in SPSS or Stata are redone in Python or R, which keeps the numbers and makes the method portable — at the cost of the interface you learned on.
