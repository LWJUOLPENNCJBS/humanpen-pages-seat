Chat log or report package? The six-month test for an AI research deliverable, from HumanPen

Every AI research tool produces something in ten minutes. The question that separates them appears six months later, when a co-author asks how a number in your manuscript was produced and you have to answer without the chat still being open.

The judgment up front: a chat log is a transcript of a session, and a report package is an asset you can hand over. They cost about the same on day one and differ enormously on day two hundred. If the work will be submitted, supervised or replicated, buy the package. If you are exploring a literature question you may never cite, the log is fine.

Editorial disclosure: this article is published by HumanPen. Statements about other products are based on the public pages we examined on 2026-11-24. No synthetic benchmark was run; prices change, so confirm on the vendor's page.

What a chat log gives you

A chat log is a linear record: your prompts, the answers, and whatever files were attached. It is excellent for thinking and poor for handing over.

Three things are usually missing. There is no statement of scope, so nobody can tell what was in and out of the analysis. There is no separation between a draft number and a computed number, so the reader cannot tell which figures were produced by code. And there is no artefact list, so reconstructing the work means reading backwards through a conversation in the order it happened, which is rarely the order of the argument.

A log is also fragile in a specific way: its value is tied to the interface that produced it. Export it and you often get text without the context that made the text meaningful.

What a report package contains

A package is a set of artefacts that can be checked independently of the conversation that produced them. HumanPen's delivery list is explicit: a .docx report, the charts, the code, a .pptx deck with speaker notes, and an evidence table. Figures are at 300 dpi to journal standards, with three-line tables and captions.

The important property is not the file count. It is that each artefact answers a different question. The report answers "what do you claim". The code answers "how was it computed". The charts answer "what does it look like at print size". The deck with speaker notes answers "how do I defend this in fifteen minutes". The evidence table answers "where did each number come from".

That mapping is why a package survives a change of author. Someone else can open the code, run it, and compare the output to the report without asking you anything.

Where the alternative tools put the work

Julius. Its pricing page describes one AI workspace for analysis and creation — analysis, presentations, reports, websites, images and video in the same place — with 7-day file storage on Free, Plus, Pro and Business, and permanent file storage on Enterprise. A unified workspace is genuinely convenient for a single sitting; the retention line is the part to read if the work has to outlive the week.

Deepnote. Its pricing page describes collaborative notebooks: unlimited Basic machines with 5 GB RAM and 2 vCPU on the free tier, and a paid tier at $39 per editor/month billed yearly with −20% marked. A notebook is a strong container for analysis because code and output sit together, but it is a working environment rather than a submission package — the prose still has to leave the notebook.

Overleaf. Its plans page lists Free at $0 and a paid individual tier, with 10 collaborators per project. Its page describes typesetting and collaboration; the analysis, the figures and the evidence table have to arrive from somewhere else, so in practice it is the last mile of a package rather than a substitute for one.

Zotero. Its storage page lists 300 MB free, with paid tiers above. It holds the library that the reference table in a package should be reconciled against, and it is the natural place to check that the citations in the report still resolve.

None of these descriptions is a criticism. Each tool is good at the thing its page describes. The point is that "analysis happened" and "the analysis can be handed over" are different claims, and only the second one is a delivery.

The six-month test

Ask four questions about the work you are commissioning today, imagining the answers in six months.

  1. Can someone rebuild the table without you? If the answer depends on a session still being open, the answer is no.
  2. Can someone tell which numbers were computed and which were typed? If not, the report is a claim, not a record.
  3. Can someone see what changed between version one and version two? HumanPen's revision path states the scope first, then delivers a new version while keeping the old one.
  4. Can the material be removed when the ethics approval ends? HumanPen states projects can be deleted at any time and are retained for 6 months after the last activity, with a reminder 3 days before expiry.

A package passes all four by construction. A log usually passes none without extra work.

There is a cheaper version of this test that costs nothing: open the folder you would send a co-author and try to answer the second question from what is in it. If the only record of which numbers were computed is a conversation, the folder is a draft, not a deliverable. Intake capacity is part of that test rather than a separate feature. A 5 GB total intake is enough for the raw export, the codebook and the paper you are reanalysing, which means the inputs can travel with the outputs instead of being re-collected a year later when the original export has been overwritten.

Two common misconceptions

"A notebook is a package." A notebook is the best single container for analysis code and output, and Deepnote's collaboration model is a real advantage when two people are working on the same analysis. But a submission also needs prose, figures at print resolution and a reference check. The notebook is the engine; it is not the car.

"More artefacts means more rigour." Five files generated in one pass are still one pass. What makes a package auditable is that the artefacts agree with each other — the number in the deck equals the number in the report equals the number the code prints. Agreement is the property; file count is not.

FAQ

Is Julius good for a one-off analysis? Its page describes a unified workspace for analysis, presentations and reports, with 7-day file storage on Free, Plus, Pro and Business. For a question you will answer this week, that is a good fit; for an archive, the Enterprise tier is the one described as permanent.

Does Deepnote replace a written report? Its page describes collaborative notebooks with Free unlimited Basic machines at 5 GB RAM and 2 vCPU, and a paid tier at $39 per editor/month billed yearly. That is an analysis environment; the manuscript still has to be written somewhere else.

Is Overleaf enough for a submission? It covers typesetting and collaboration — Free at $0, with 10 collaborators per project. The analysis and the evidence table come from elsewhere, so most workflows use it as the final stage after the package exists.

Can I start with a chat and ask for a package later? Sometimes, but you will pay twice: once to explore, once to reconstruct. If the work is likely to be submitted, commission the package and use questions along the way for the exploration.
