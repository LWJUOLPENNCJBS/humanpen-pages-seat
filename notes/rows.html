Rows vs HumanPen Start Project: A Spreadsheet With AI Tasks vs a Project That Ends in a Report

Rows is the better choice when the work lives in a grid and the question is "what does this table say". It is a spreadsheet with AI tasks attached to it, and it is priced by how many of those tasks you get each month: Free includes 5 AI Tasks a month, Plus is $8 per user per month for 200 a month, and Pro is $79 a month plus $8 per user per month for 1,000 a month.

HumanPen Start Project is the better choice when the table is the input rather than the product. You attach the data, get a plan, confirm it, and receive the analysis, the charts and a written report — a .docx document, 300 dpi figures, three-line tables, a .pptx with speaker notes, and the code that produced every number.

One keeps your work in a spreadsheet and answers questions about it. The other takes the data out of the grid and returns a document that can go into a submission.

Two facts shape the rest of this comparison. Rows limits file imports to 1 MB on Free, 5 MB on Plus and 100 MB on Pro. And both pages we examined carry a notice worth reading before you commit: "Rows has joined Superhuman". Neither page describes what that means for existing workspaces, so treat the product's future as something to ask about rather than something this article can tell you.

How the workflows differ

1. The table is the product vs the table is the input

Rows is built around a grid you keep working in. The AI is applied to what is already there — extract, analyse, summarise — and the artefact at the end of the session is the same spreadsheet, now with more in it. For a recurring operational task that is exactly right: the file stays live and nobody has to reconcile a document against a source table.

HumanPen Start Project assumes the grid is a means. The deliverable is a report with a methods paragraph, tables built to a journal's conventions, figures at 300 dpi, and the code that regenerates them. The page's worked example is a secondary analysis of the International Stroke Trial — 19,435 patients in the full analysis set, 62.2% of the aspirin group and 63.5% of the control group dead or dependent at 6 months, OR 0.95 (0.89–1.00), P = 0.072, with about 150 missing outcomes handled in a sensitivity analysis. Those numbers are computed, checked and then written up in prose that keeps them intact.

The practical test is simple. If your output is a spreadsheet somebody will keep updating, Rows matches the shape of the work. If your output is a document somebody will review, the spreadsheet is an intermediate artefact.

2. AI tasks vs a confirmed plan

Rows meters AI in tasks: 5 a month on Free, 200 on Plus, 1,000 on Pro. That is a fine unit for a spreadsheet, because the work is naturally incremental — one extraction here, one summary column there — and a monthly allowance tells you how much iteration you can afford before you start.

HumanPen's unit is the project, and the control is a checkpoint. The stages are Describe, Plan, In progress, In review, Delivered, and the rule on the page is "Plan first, start when you confirm". Before the first line of code runs, the project restates the brief — analysis set, endpoint, how missing outcomes will be handled — and waits for your approval. A second AI reviews the result before delivery; the page shows it as "Review passed (round 1)", with the primary endpoint matching, the analysis populations adding up, a clean rerun reproducing the numbers and all 11 references found one by one.

A task allowance optimises for many small moves. A plan checkpoint optimises for one move that is right. Neither is better in the abstract; they suit different failure modes.

3. 100 MB vs 5 GB

The file ceiling is where the two products separate most sharply, and it is stated, not inferred: Rows lists imports of 1 MB on Free, 5 MB on Plus and 100 MB on Pro. HumanPen lists Excel, CSV, Word, PDF and zip up to 5 GB total per project.

For a marketing export or a small operational table, 100 MB is generous. For research data it often is not. A survey with open-text fields, a cohort extract with repeated measures, a zip of 300 PDFs for an evidence table — these routinely pass 100 MB before anyone has started cleaning. At that point the choice is not about features; it is about whether the file fits.

The other ceiling is time. A spreadsheet assumes you will come back. HumanPen assumes the project ends: work is delivered, versions are kept, and the project is retained for 6 months after the last activity with a reminder 3 days before expiry. If the analysis is going to be re-opened during a revision, the retention line matters more than the task count.

Uploading files and what comes back

Rows takes files into a spreadsheet, with the ceiling above, and returns the spreadsheet plus whatever the AI tasks produced inside it. The pages we examined describe imports and AI tasks; they do not describe a delivered report, figure set or slide deck, and they do not state a total intake per workspace beyond the per-file import size.

HumanPen Start Project specifies both ends. Intake: Excel, CSV, Word, PDF and zip, up to 5 GB total. Output: a .docx report, charts at 300 dpi to journal standards, three-line tables and captions, a .pptx with speaker notes, and the code. The page is equally plain about limits — analysis runs on Python or R, SPSS and Stata analyses are redone in Python or R, Wind and CNKI data must be exported first, and GPU training is not yet supported.

That last clause matters. A tool that states what it will not do saves a week of discovering it — if your design needs a GPU-trained model, the page tells you before you upload anything.

Price shape and governance

Rows prices per user with a monthly task allowance: Free at $0 with 5 AI Tasks a month; Plus at $8 per user per month with 200 a month; Pro at $79 a month plus $8 per user per month with 1,000 a month. Pro is the interesting one, because it is a platform fee plus a seat fee — sensible for a team sharing one heavy workspace, awkward for a single researcher, since $79 plus $8 is the entry ticket either way.

HumanPen sells credits rather than subscription seats, so this comparison quotes no per-month figure for it. What the pages do publish is the shape of the commitment: a plan you approve before work starts, revisions raised inside the project with the scope explained first, a new version delivered while old versions are kept, and 6 months of retention after the last activity.

On governance, the two pages speak to different buyers. Rows' pricing page is written for a workspace administrator, with plans, members, guests and integrations. HumanPen's page is written for someone who has to answer a data-management question: transport encryption, an isolated sandbox per project, no sharing across users, no use for training, deletion at any time. The developer page adds the machine-readable layer — an API at https://api.humanpen.net/v1, a confirm_plan call carrying a spec_version, short-lived signed URLs for the delivery zip, and webhooks that contain only the project and its state.

One caution that has nothing to do with features: "Rows has joined Superhuman" appears on both pages we captured, and a reader comparing tools in late 2026 should read that line before signing an annual commitment. The pages do not describe migration, continuity or roadmap, so the honest position is that this is a question for the vendor.

When to choose which

Choose Rows if the work is a live table that several people touch: a tracking sheet, a recurring report, a small model with inputs that change weekly. The AI tasks are a light layer on top of a familiar grid, and the Free tier's 5 a month is enough to test the idea.

Choose HumanPen Start Project if the work has to leave the spreadsheet: a paper's results section, a clinical report, a grant's preliminary analysis, a lab meeting deck built from a finished analysis. The plan checkpoint, the second-AI review, the 5 GB intake and the delivered code are for that handover, and 6 months of retention covers the revision cycle that follows.

Use both if the data has a life before and after the analysis. Keep the working table in Rows so the team can maintain it, then hand the snapshot to HumanPen Start Project, confirm the plan, and take delivery of the report, figures and code. The spreadsheet stays the operational record; the project produces the document that cites it.

The mismatch to avoid is expecting a spreadsheet to write the paper, or expecting a report pipeline to be where your team maintains a living dataset. They are different artefacts with different lifespans, and confusing them is how numbers drift between table and manuscript.
